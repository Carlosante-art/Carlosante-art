Four domains, one idea: model the individual from their own data, not the average. Numbers are computed in code, the AI only interprets, and the person has the last word.

#### In plain words

- **Selvra:** an AI memory that you own. You never have to start over in a new chat.
- **Stillra:** a personal assistant for people with diabetes. It reads the glucose sensor and prepares a summary for the doctor.
- **Forsyne:** a health coach that learns how your body works and predicts how you will feel tomorrow.
- **Motiq:** an AI that learns your personal style as a musician.

#### How I build

- **Privacy by design.** Each user's data is isolated from everyone else's. Built to follow data protection principles such as GDPR: users can see, export and delete their data.
- **Secure storage.** Sensitive data is encrypted. Built for EU hosting.
- **Safe AI.** The AI is never allowed to make up numbers. Every answer is checked before a person sees it, and every claim shows where it came from.
- **Reusable modules.** One shared core (Selvra) powers several products, so each new product is built on parts that are already tested.
- **Tested.** More than 1,500 automated tests across the projects.

What I do in all four: collect messy data from many sources, clean and structure it, calculate reliable numbers, and turn them into insights people can understand and trust.
